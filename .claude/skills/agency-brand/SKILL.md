# Skill: agency-brand

The canonical brand reference. Every content and deck step reads this before producing anything.
In this public repo the agency is **Studio Rantai**, a FICTIONAL Jakarta creative studio used for
the demo. To run the factory for a different agency, edit `config/brand.json`, `templates/tokens.css`
and re-run `./run.sh tools/make_brand_assets.py` (or drop in real logo PNGs at the paths in brand.json).

## Who the agency is (read `config/brand.json`)
- **Name / tagline / handle / contact block** — `name`, `tagline`, `handle`, `contact`.
- **Philosophy** — `philosophy` ("Ideas before price lists. We build narratives."). Every proposal
  leads with an idea, never a price list. We sell strategy and story, not a booking service.
- **Three pillars** — `pillars` (Insight first · Story second · Craft always). Rendered on `why_agency`.
- **Headline stats** — `stats_sample`. In the demo these are SAMPLE numbers; a real deployment must only
  put verified figures here.

## Voice
Strategic, creative, confident, direct. Casual-professional, never corporate-stiff. Short declarative
headlines. Light Indonesian Gen-Z slang in creator-facing copy only. **Do:** lead with the narrative,
name the big idea, tie every choice back to the story. **Don't:** open with a price list, use
stock-photo filler, present creators as plain names, or print an unverified number as fact.

## Visual identity (source of truth: `templates/tokens.css`)
- **Surfaces:** white `#FFFFFF`; subtle `#F9FAF9`; dark bands ink `#0E1512`.
- **Primary:** deep forest green `#1F5240` (`--primary-*` ramp). **Accent:** warm sand `#C99A45` (`--accent-*`).
- **Headlines:** Plus Jakarta Sans 800, tight tracking, sentence case.
- **Eyebrows:** Space Mono, uppercase, letter-spacing 0.18em — primary on light, accent on dark.
- **Texture:** generated topographic contour PNG on dark bands only (screen blend, ~24% opacity).
- **Per-client blend:** set `meta.accent_hex` to the client's colour; it becomes `--accent-client`.

Templates only reference role ramps (`--primary-*`, `--accent-*`), never a literal hue, so a re-skin
never touches `deck.css` or the slide macros.

## Brand assets (generated by `tools/make_brand_assets.py`)
- `assets/logo/studio-rantai-wordmark-color.png` / `-white.png` / `.svg`
- `assets/texture/contour-texture.png`
- Fonts (OFL): `assets/fonts/PlusJakartaSans-VariableFont_wght.ttf`, `SpaceMono-Regular.ttf`, `SpaceMono-Bold.ttf`
The deck renderer inlines all of these automatically.

## Services (see `config/services.json` for deliverable menus)
Influencer Marketing · Creative Strategy · Creative Content Production · Events Visit Organizer ·
Web Development. Only put the services that fit the campaign into the deck.

## Money & language
IDR everywhere (`Rp 1.650.000.000`, dots as thousands, via `_util.rp()`). English by default;
Bahasa Indonesia on request (`meta.language: "id"`).
